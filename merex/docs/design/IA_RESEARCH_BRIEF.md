# IA research brief (Part A3)

## Goals

- Validate **creator** vs **business** primary tasks and frequency.
- Confirm labels: **Campaign** (business) vs **Opportunity** (creator) vs internal `Requirement`.
- Confirm **Deal** = `Contract` in UI everywhere users see collaboration state.

## Success criteria

- Users can name **one** next action on Home without coaching.
- “Application” vs “Deal” confusion rate **↓** after labels + timeline.
- Business users find **Applicants** queue without using only dashboard shortcuts.

## Hypotheses to test (card sort + interviews)

1. Creators think in **opportunities → applications → deals** sequentially.
2. Brands think **campaign → applicants → deliverables → payouts** as separate queues.
3. **Projects** (if present) is confused with **Deals** — prefer merge or rename to “Content calendar.”

## Label candidates

| Internal | Creator UI | Business UI |
|----------|------------|-------------|
| `Requirement` | Opportunity | Campaign |
| `Contract` | Deal | Deal |
| `Application` | Application | Applicant |
