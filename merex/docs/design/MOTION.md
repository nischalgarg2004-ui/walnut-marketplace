# Motion tokens (Part B2)

| Token | Value | Use |
|-------|-------|-----|
| `fast` | 150ms ease-out | Hover, focus |
| `medium` | 200ms ease-out | Sheets, dropdowns |
| `slow` | 250ms ease-out | Modals |

**Reduced motion:** `@media (prefers-reduced-motion: reduce)` — instant opacity, no slide (see `globals.css`).
