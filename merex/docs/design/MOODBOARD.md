# Merex — Moodboard & reference products

**Status:** Design direction (Part A1). **Do not treat as final brand law**—validate with users.

## North star: proof-first rhythm

- [Wispr Flow](https://wisprflow.ai/) — confident headline hierarchy, before/after transformation demos, metric callouts, dark polished frames, social proof bands. **Translate:** messy brief → structured opportunity/deal; no voice features implied.

## Reference products (patterns, not pixels)

| Product | Borrow |
|---------|--------|
| **Vercel / Geist** | Neutral surfaces, single accent, monospace for data |
| **Stripe Dashboard** | Dense tables, sticky headers, row actions, clear money lines |
| **Linear** | Sidebar + keyboard affordances (⌘K placeholder), status pills |
| **Notion** | Sidebar clarity, readable body, restrained chrome |

## Accent direction options (pick one in Figma)

1. **Teal electric** — `#0d9488` / `#14b8a6` (professional, distinct from “default purple SaaS”).
2. **Coral action** — `#ea580c` / `#f97316` (warm, creator-friendly).
3. **Slate + lime** — near-black UI with `#a3e635` accent (high contrast “pro tool”).

**Implementation default:** Teal scale in `globals.css` / Tailwind theme until brand locks.

## Proof / demo moments (marketing + onboarding)

- **Before:** long DM-style brief → **After:** Opportunity card + deadlines + compensation.
- **Metric callouts** only when backed by real product data (e.g. pending counts), never fabricated “4x” claims.
